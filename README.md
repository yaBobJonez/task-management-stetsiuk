# Програма управління задачами

## Опис проєкту

Цей репозиторій містить проєкт Михайла Стецюка (Б-121-22-1-ПІ) для лабораторної №2 з
дисципліни «Основи DevOps інженерії» — застосунок для управління задачами за підходом
Kanban-дошки. Програма буде написана мовою C++ із використанням фреймворку Qt 6.
Встановлюватиметься локально, тому дані будуть зберігатися на компʼютері у вигляді
CSV файлу.
